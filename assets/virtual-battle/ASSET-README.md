# TM Virtual Battle assets

The first animated fighter pass uses CC0 assets supplied by the project owner.

## Runtime files expected by Phaser
Place the optimized WebP sheets at `assets/virtual-battle/sprites/`:
- swordsman-idle.webp, swordsman-run.webp, swordsman-jump.webp, swordsman-attack.webp, swordsman-skill.webp
- golem-idle.webp, golem-walk.webp, golem-attack.webp, golem-hurt.webp, golem-death.webp

The six effects sheets are included for the next effects integration pass. Four portrait samples are included for future fighter-selection UI.

## Source and license
The uploaded SpriteCanvas swordsman, golem, and effects packs each include a CC0 1.0 notice. The anime portrait and village packs declare CC0 in their included license/manifest. Original ZIPs and notices should be retained alongside this optimized runtime bundle.

See `ASSET-LICENSES.txt` and `ASSET-REGISTER.csv` in the supplied bundle. The WebP sheets are optimized derivatives of the supplied PNG sprite sheets; animation frame dimensions are preserved.
